# TESI2105_Programa_Evolutivo_ReyesJuan
Programa: BoriTech - Control de Inventario Electrónico

Problema que atiende: Evita tener que sacar cuentas a mano o en calculadora al recibir mercancía, reduciendo los errores al calcular totales, impuestos y descuentos.

Usuario principal: El personal de almacén, encargados de inventario o dueños de pequeños negocios de tecnología.

Descripción del programa: Este programa es una herramienta sencilla para registrar la entrada de equipos electrónicos a un negocio de manera rápida. El usuario solo tiene que ingresar el nombre del equipo, cuántas unidades llegaron y el precio individual. Con esos datos, la aplicación hace los números por sí sola: verifica que los datos no estén en negativo, calcula el impuesto del IVU y aplica un descuento si la compra es grande. Además, permite seguir metiendo más artículos seguidos sin que se cierre la pantalla y al final saca un recibo bien detallado con todo lo que se gastó.
